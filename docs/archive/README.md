# Archive

Frozen design and research notes from the pre-1.0 era (Python implementation, TS migration planning).

These docs are kept for historical reference only — they describe a system that no longer exists in this form. The current architecture is documented in [docs/ARCHITECTURE.md](../ARCHITECTURE.md) and the source under `src/`.

- `plan/` — architecture sketches, phased implementation plans, packaging notes that drove the original Python build and the TS migration waves.
- `research/` — background investigation into subprocess management, tmux, daemons, task queues, telegram file handling, and other primitives evaluated during design.

For the Python implementation source, see the `v0.5.10-python-final` git tag.
